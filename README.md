# Blue Team Write-ups

Write-ups that turn offensive findings into practical blue team skills: detection, hunting, and mitigation.

## About

This repository contains security write-ups focused on the defensive side of cybersecurity.  
Each write-up analyzes real techniques, vulnerabilities, or attack paths and extracts actionable value for blue teams:

- Detection opportunities
- Hunting hypotheses
- Logging & visibility gaps
- Mitigation recommendations
- Lessons learned

The goal is simple: take something that usually lives in the red team / offensive world and make it useful for defenders.
